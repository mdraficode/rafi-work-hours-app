# Rafi's Work Hours

The web app (single self-contained `index.html`) for logging Arctic tour work hours with automatic Sunday/holiday doubling, paid tracking, income stats and reports.

**Live app:** https://mdraficode.github.io/rafi-work-hours-app/

Your actual work records are **not** in this repository. They are stored in the private repository
`mdraficode/rafi-work-hours` (file `data/records.json`) and sync there automatically from the app.
